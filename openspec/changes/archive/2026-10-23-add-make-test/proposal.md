# Proposal

## Why

Локальные unit-тесты сейчас запускаются только через `make check` вместе с проверками Git diff. Нужна отдельная привычная команда `make test` для запуска существующего набора тестов.

## What Changes

- Добавить phony-цель `test`, запускающую `test/logging.py` и шесть существующих eval-групп.
- Перенести тестовые команды из `check` в `test`, а `check` связать с `test` зависимостью, сохранив обе проверки Git diff.
- Обновить `docs/testing.md`: описать `make test`, необходимые `ly2k` и Python 3, а также назначение `make check`.
- Сохранить передачу ошибки теста через ненулевой код завершения `make`.

## Capabilities

### New Capabilities

Нет. Изменение касается инструментария разработки; в `.openspec.yaml` задано `skip_specs: true`.

### Modified Capabilities

Нет. Поведение приложения и проверяемые сценарии не меняются.

## Impact

Изменяются `Makefile` и `docs/testing.md`. Используются существующие тестовые команды без новых зависимостей. `make test` работает локально без сборки APK, Android-устройства и проверок Git diff. Цель по умолчанию остаётся `build`.
